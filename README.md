## 💻 Local Development

Clone the repository and launch the local environment:

```bash
# Clone the repository
git clone https://github.com/AMChethan/amchethan-portfolio.git

# Navigate into the project directory
cd amchethan-portfolio

# Install development dependencies
npm install

# Start the Vite development server
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
