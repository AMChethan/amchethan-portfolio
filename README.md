---

## 🌟 Key Highlights

- **Dynamic Theme Dock**: Switch between 4 curated themes on the fly:
  - 🟢 **Cyber Emerald** (AI & Systems)
  - 🟣 **Electric Violet** (Modern Linear Style)
  - 🔵 **Hyper Cyan** (Deep Marine)
  - 🔴 **Sunset Coral** (Warm Ember)
- **Fluid Interactive Background**: Custom canvas-rendered particle field with cursor gravitational lensing and harmonic wave motion.
- **Card Deck Pinning**: Physics-based card stacking interactions powered by GSAP & ScrollTrigger.
- **Interactive AI Recruiter Terminal**: In-browser CLI simulator answering queries about technical architecture, system design, and project specifics.
- **Full SEO & Social Optimization**: Open Graph tags, semantic HTML5, accessible markup, and responsive layouts for all device form factors.

---

## 🛠 Tech Stack

- **Core**: HTML5, Vanilla CSS3 (Custom design system with tokens & themes), Modern JavaScript (ES6+)
- **Animation & Physics**: GSAP 3, ScrollTrigger
- **Dev Tooling**: Vite
- **Deployment**: GitHub Pages

---

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/AMChethan/amchethan-portfolio.git
cd amchethan-portfolio
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
